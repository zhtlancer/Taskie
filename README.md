## 📖 项目简介

**Taskie (嗒嗒日常)** 是一款专为家庭场景设计的小学生日常作业与学习任务管理系统。

摒弃了传统家校软件臃肿的社交与营销功能，以**孩子自主打卡**为核心，深度针对 **iPad Air 5 横屏视口 (1180 × 820 px)** 进行触控与视觉定制，手机和竖屏 iPad 也有专门的单列布局。集**日常作业打卡**、**趣味激励成长**、**拍照错题本**、**生字生词本与查笔画**于一体，让孩子在正向激励中养成专注自律的好习惯。

## ✨ 核心功能全览

### 1. 🐱 多孩子账号与独立隔离
- **可爱头像选择**：首页直观的 Emoji 萌宠卡片（如 🐱 小明、🐰 小红），一键点击切换；
- **独立 PIN 码保护**：孩子可选配置专属 4 位数字密码，任务进度、积分金币、勋章与错题严格账号数据隔离；
- **独立家长管理入口**：右上角家长控制台设有独立 PIN 码门禁，防止孩子误改配置。

### 2. 📋 每日作业任务看板 (iPad Air 5 横屏优化)
- **大卡片一屏全览**：在 1180 × 820 px 视口下无需滚动即可掌控今日全部作业，触控目标 ≥ 48×48px，防误触；
- **中文字体专属设计**：甄选适宜小学生语文认读的开源名作 **霞鹜文楷 (LXGW WenKai)**，配合规范的 **思源黑体**、童趣 **站酷快乐体** 标题与圆润英文字体 **Nunito**；
- **按孩子分配任务**：每个任务模板可以给全部孩子，也可以只给指定的孩子，适合不同年级；
- **临时任务**：老师当天临时布置的作业，家长在总览中给某个孩子的某一天添加，卡片带“临时”标记，和日常任务一样打卡、计入全勤与统计；
- **灵活双模式周期配置**：
  - **模式一（固定星期）**：如周一到周五每日生成“数学口算打卡”；勾选每天则周末也包括；
  - **模式二（每周特定次数）**：如“每周完成 3 次课外阅读 20 页”，卡片动态跟踪周完成进度（`🎯 周目标 3次 · 本周已完成 2/3`）；还可以限定可完成的日子，例如“周末作业，每周 1 次，限周六、周日”。
- **弹性与必做**：每周任务在本周还有余量时显示“🌤️ 今天可选”，不做也不影响当天全勤；当剩余次数等于剩余可做天数时变为“⏰ 今天要做”。
- **申请跳过**：某天没有这项任务（如老师没布置），孩子点卡片上的“🙋 今天没有？”并写下理由（必填），家长在总览中同意或拒绝；家长打开孩子看板也可以直接跳过或撤销跳过。跳过的任务不得分，不计入完成度，也不打断全勤和连续打卡（当天任务全部跳过就算休息日）；每周任务跳过一次算用掉一次周目标，长期任务的“每天要记录”也可以跳过当天。申请被拒绝或跳过被撤销后，孩子当天不能再为这项任务申请；孩子直接完成任务会自动撤回申请。
- **任务计时与用时**：家长在任务模板、临时任务或长期任务上勾选“⏱ 记录用时”，可选填预计用时。孩子可以在卡片上开始、暂停、继续或清零计时（同一时间只计一项，开始新的会自动暂停其他），完成时自动记下计时；没有计时（不到 1 分钟）或计时超过 3 小时时，会请孩子选一下用了多久，也可以不填。有预计用时时显示“还剩 X 分钟 / 超时 X 分钟”。孩子当天可以修改或补填用时，家长可以修改任意一天。计时保存在服务器上，锁屏、刷新或换设备都不会中断。长期任务每次记录进度时保存这一段的用时，然后重新计时。

### 3. 🏆 趣味激励系统与交互音效
- **即时正向反馈**：点击打卡触发卡片微动效与金币飘洒动画；
- **连续打卡火焰 (Streak)**：累计连续完成作业天数，跳动火焰动效实时激励；没有安排任务的休息日（如只有工作日任务时的周末、假期中暂停的日子）既不计入也不打断；
- **8 大里程碑勋章墙**：初出茅庐、三连击、一周勇士、月度冠军、小富翁、积分达人、全勤王、优秀学生，达成自动点亮；
- **全勤礼花庆贺**：当天必做任务全部完成时触发全屏彩色纸屑粒子动效；
- **积分兑换商城**：家长设置奖励（如“看 30 分钟动画 = 50 分”），孩子用积分申请兑换，家长确认或拒绝；申请期间积分先冻结，拒绝或撤回后退回；
- **自研 Web Audio 原生音效**：
  - 零外部音频文件依赖，离线秒开，iPadOS 完美支持；
  - 包含金币音 (Coin)、胜利号角 (Fanfare)、勋章叮当音 (Chime)、轻触水滴气泡音；
  - **全局声音开关**：顶部常驻 🔊 / 🔇 开关，状态本地持久化保存。

### 4. 📸 拍照错题本 (触控裁剪 + 自动锐化压缩)
- **原生相机集成**：点击直接调用 iPad 原生后置高清相机拍照或相册选图；
- **多点触控自由裁剪**：基于九宫格辅助线自由拉伸四角框选题目区域，支持 90° 旋转校正；
- **试卷文档增强模式**：
  - **原图模式**：保留真实色彩；
  - **清晰增强（推荐）**：应用拉普拉斯锐化矩阵去除纸张灰暗底色、加黑铅笔与墨水字迹；
  - **黑白文档模式**：自适应阈值二值化（纯白纸张、加黑字迹），便于日后打印重练；
- **服务端 Sharp 高效压缩**：自动校正 EXIF 拍摄方向，将几兆原始照片压缩为 **150KB~250KB WebP** 格式，兼顾画质与轻量存储。

### 5. 📖 生字生词本与 🔍 查笔画系统
- **「🔍 查笔画」**：
  - 输入汉字或词语（最多 8 个字），在超大米字格中动态演示**逐笔笔顺书写动画**（基于 `hanzi-writer`，支持步进播放与重写）；词语可逐字点选查看；
  - 实时解析部首、总笔画数、带声调拼音（词语整词注音，多音字按词读，如“银行”读 yín háng），支持点击「🔊」朗读；
  - 醒目大按钮「⭐ 加入生字生词本」，可同时标记分类，一键存入。
- **「📖 生字生词本」**：
  - 田字格卡片流（霞鹜文楷书法字体展示），词语按字排成多个田字格；
  - **拼音默认遮罩隐藏**，点击卡片「👁️ 拼音」翻牌显露，专为自主认字背诵与默写自测设计；
  - 点开详情卡片支持在 iPad 屏幕上进行**手指描红临摹**练习；
  - 支持按“已掌握 / 学习中”过滤，并可按 **会认读、会写、笔画要改正、易错字** 四个分类筛选；一个字词可以有多个分类；
  - **孩子可以添加分类，去掉分类只有家长可以**（家长在「家长后台 → 孩子账号」点该孩子的「📖 字词本」打开即可）；带分类的字词孩子不能移出，以免纠错标记被删掉；
  - 笔顺数据随应用打包（约 9500 个汉字），不依赖外网 CDN；书法字体仍从 jsDelivr 加载，加载不到时会退回系统字体。

### 6. 📚 长期任务与 🏖️ 节假日、寒暑假
- **长期任务**：需要多天完成的任务，如“读完《西游记》共 200 页”或“口算练习册 50 页，周五前完成”；
  - **两种记录方式**：“读到第几页”（孩子记录读到的位置，系统自动算出今天读了多少）或“今天完成了多少”；也可设为“完成后打勾”；
  - **节奏提示**：有截止日期时显示“还剩 5 天 · 今天建议再做 10 页”，没有截止日期时按最近 7 天的速度估算“预计 11/1 完成”；
  - **积分**：按进度分次得分（如每页 1 分），全部完成再得完成奖励；撤销记录会扣回对应积分；
  - **每天要记录**：可选，开启后成为每天的必做项，当天记录一次进度才算全勤；
- **按孩子设置假期**：为每个孩子设置国庆、寒假、暑假等日期范围，同一孩子的假期不能重叠；
- **选择假期中继续的任务**：家长勾选哪些日常/每周任务在假期中继续，其余暂停；暂停的任务不生成、不计入完成度、不打断连续打卡；
- **假期任务**：如“寒假作业 共 40 页，每页 2 分”，即日期跟随假期的长期任务；家长可补记或更正进度记录。

### 7. 📈 周完成度与学习历史
- **本周完成度（截至今天）**：固定星期任务按已到期的日子计算，每周任务只计算本周已无法再补的次数，提前完成的照样计入；没打开 App 的日子也算在内；
- **本周与上周对比**：孩子的历史统计页显示每项任务的本周进度，家长总览显示每个孩子的本周与上周完成度；
- **近 7 天趋势**：每日完成率柱状图，休息日单独标出；
- **长期任务进度曲线**：显示每天累计读到的页数，有截止日期时叠加计划进度参考线。

### 8. 📱 手机适配与 PWA 独立全屏模式
- **手机与竖屏 iPad**：宽度小于 1024px 时切换为单列布局；孩子端底部有“今日 / 积分 / 错题 / 字词 / 历史”标签栏，科目改为横向滑动，家长端导航改为两行；iPad 横屏保持原有布局；
- 内置 Web App Manifest 与 Apple 移动设备独立运行标签（`apple-mobile-web-app-capable: yes`），横竖屏均可使用；
- 在 iPad 或手机的 Safari 中点击 **分享 ➡️ 添加到主屏幕**，即可在桌面上生成独立 App 图标；
- 点开后**100% 独立全屏运行**，彻底去除顶栏网址输入框与底栏标签页，专注防误触。

### 9. 👨‍👩‍👧 家长后台管理
- PIN 码保护，孩子无法误入修改；首次使用默认 PIN 登录后必须先设置新 PIN；
- 孩子账号管理（姓名、头像 Emoji、PIN 码）；
- 任务模板管理（分值权重、学科分类、星期与周频次、适用孩子）、临时任务、长期任务与假期安排；
- 奖励兑换管理与兑换审批；
- 数据总览、孩子完成率历史趋势图表（基于 Chart.js）与备份恢复。

## 🚀 快速开始

### 方式一：Docker / Docker Compose 部署（强烈推荐，一键运行、零配置）

项目已完整内置多阶段 `Dockerfile` 与 `docker-compose.yml`，支持零环境依赖一键容器化启动。
前端静态资源自动构建并由后端统一托管，数据持久化保存在宿主机 `./data` 目录。

```bash
# 1. 启动容器（后台常驻运行，自动构建前端与后端环境）
docker compose up -d

# 2. 查看运行日志
docker compose logs -f

# 3. 停止容器
docker compose down
```

启动完成后，直接在 iPad 或电脑浏览器中访问：
- **Web 应用与打卡入口**：`http://<服务器局域网IP>:3000`（本机：`http://localhost:3000`）
- **首次设置**：
  1. 第一次打开会显示 6 位**配对码**（设备授权，见下文「设备授权与公网访问」）。在服务器上运行 `docker exec taskie-app node src/cli.js approve-device <配对码> 我的iPad` 授权第一台设备，页面会自动进入应用；
  2. 点击右上角「家长入口」，用初始 PIN `1234` 登录后按提示设置新的家长 PIN，再添加孩子和任务；
  3. 之后的新设备（手机、另一台平板）在「备份与设置 → 设备授权」中输入它显示的配对码即可授权；
- **持久化数据存储**：
  - 数据库文件：宿主机 `./data/data.sqlite`
  - 错题照片目录：宿主机 `./data/uploads/`
  容器更新、销毁与重建过程中，所有作业记录与错题照片均持久保存在宿主机，永不丢失。

> 💡 **已有本地数据迁移至 Docker（可选）**：
> 若此前在本地裸机运行过已有数据，执行以下命令即可平滑迁移进 Docker 挂载卷：
> ```bash
> mkdir -p data
> cp backend/data.sqlite data/data.sqlite 2>/dev/null || true
> cp -r backend/uploads data/ 2>/dev/null || true
> ```

### 方式二：群晖 NAS (Synology) 预构建镜像部署指南（免编译、首选推荐）

群晖 NAS 硬件配置（如赛扬 J4125、Realtek ARM）性能有限，**强烈建议直接使用云端自动预构建好的轻量多架构镜像**，避免在群晖本地进行耗时的 npm 依赖下载与前端编译。

项目已配置 GitHub Actions 自动流水线，每次提交均自动构建多架构镜像并发布到 GitHub Container Registry：
`ghcr.io/zhtlancer/taskie:latest`（同时原生支持 `linux/amd64` 与 `linux/arm64`）。

#### 方案 A：群晖 Container Manager 图形界面直接运行（无需下载源码，仅需 1 个文件）

1. **新建配置目录**：打开 DSM「File Station」，进入 `docker` 共享文件夹，新建 `taskie` 文件夹；
2. **创建项目**：
   - 打开群晖 **Container Manager** ➡️ 点击左侧 **「项目」** ➡️ 点击 **「新增」**；
   - **项目名称**：输入 `taskie`；
   - **路径**：选择刚才创建的 `/docker/taskie` 目录；
   - **来源**：选择「创建 docker-compose.yaml」，并将下方内容粘贴进去：
     ```yaml
     services:
       taskie:
         image: ghcr.io/zhtlancer/taskie:latest
         container_name: taskie-app
         restart: unless-stopped
         ports:
           - "3000:3000"
         volumes:
           - ./data:/app/data
     ```
   - 点击下一步，勾选「向导完成后立即启动项目」并完成。
3. 群晖将直接从云端高速拉取预构建镜像，秒级完成启动！

#### 方案 B：群晖 SSH 命令行一键运行（直接拉取预构建镜像）

```bash
# 1. 登录群晖 SSH
ssh <群晖管理员用户名>@<群晖局域网IP>

# 2. 创建目录并启动
mkdir -p /volume1/docker/taskie/data
cd /volume1/docker/taskie

# 3. 直接以后台方式运行预构建镜像
sudo docker run -d \
  --name taskie-app \
```

#### 方案 C：离线导入预构建镜像（适用于 NAS 无法直接联网拉取的情况）

若群晖所在局域网无法直接拉取 GitHub 容器镜像：
1. 在个人电脑（Mac/Windows/Linux）上构建并导出压缩包：
   ```bash
   docker build -t taskie:latest .
   docker save taskie:latest | gzip > taskie.tar.gz
   ```
2. 将 `taskie.tar.gz` 上传至群晖 File Station 的任意目录；
3. 打开群晖 **Container Manager** ➡️ 左侧 **「映像」** ➡️ 点击顶部 **「操作」** ➡️ **「导入」** ➡️ 选择「从文件添加」并选中上传的 `taskie.tar.gz`；
4. 导入完成后选中该映像点击「运行」，设置端口映射 `3000:3000` 与文件夹挂载 `/docker/taskie/data -> /app/data` 即可立即启动。

> 📌 **群晖部署小贴士与常见问题**：
> 1. **提示 unauthorized 报错解决**：
>    GitHub Packages 镜像仓库默认将新建镜像设为私有 (Private)。请在 GitHub 仓库主页右侧点击 **Packages** ➡️ 点击 `taskie` ➡️ **Package settings** ➡️ 滚动到底部 **Danger Zone** ➡️ 点击 **Change visibility** 改为 **Public** 即可公开免密拉取；或者在群晖执行 `docker login ghcr.io` 登录具备 `read:packages` 权限的 GitHub Token。
> 2. **运行用户与权限**：容器以普通用户（默认 uid/gid `1000`）运行程序，启动时会自动把 `data` 目录交给该用户，旧版本创建的文件也会一并处理，升级无需手动操作。默认 uid `1000` 在群晖上通常不对应任何账户，文件属主会显示为数字，这不影响使用，并且容器即使被攻破也几乎访问不到 NAS 上的其他文件。若希望属主显示为名称，请在 DSM 中新建一个专用普通账户（如 `taskie`，不加入 administrators 组、不授予其他共享文件夹权限），在 SSH 中执行 `id taskie` 查看 uid/gid，再设置 `PUID`、`PGID`。**不要填写管理员账户**，否则容器被攻破时可能获得该管理员的文件权限。若在 compose 中用 `user:` 指定运行用户，容器不会自动调整权限，日志提示“数据存储目录没有写权限”时，请在 File Station 中为该用户授予 `/docker/taskie` 的读写权限。
> 3. **iPad 桌面独立 App**：在 iPad Safari 中打开 `http://<群晖IP>:3000` ➡️ 点击分享按钮 ➡️ 选择「添加到主屏幕」，即可体验如同原生 App 的沉浸式无边框全屏打卡！
> 4. **外网与 HTTPS 访问（可选）**：如需在外网打卡，可在群晖「控制面板」➡️「登录门户」➡️「高级」➡️「反向代理服务器」中配置一条反向代理规则，将域名与 SSL 证书映射至 `localhost:3000`。

## 💾 数据备份与迁移

### 家长端备份与恢复

登录家长后台，打开「备份与设置」：

- 「立即创建备份」会保存数据库（账号、任务、积分、兑换、假期、长期任务与生字生词及其分类等）及关联的错题照片，支持下载 `.taskie.gz` 备份包。
- 默认每 24 小时自动备份，保留最近 7 份；启动时若没有备份或最近备份已过期，会立即补做。
- 恢复需要当前家长 PIN 和确认勾选。系统先验证备份，再保存恢复前快照；数据库恢复失败会回滚数据库和照片目录。
- 恢复完成后所有会话失效，需要重新登录。备份中的账号、PIN 和学习记录会替换当前数据。
- 上传最大 64 MiB，解压后的备份最大 256 MiB；更大数据请使用 NAS 文件备份，并在停服后复制完整数据目录。

Docker 部署的自动备份位于宿主机 `./data/backups`，数据库和照片在 `./data/data.sqlite`、`./data/uploads`。请定期将备份下载到另一台设备，NAS 上的同盘副本无法覆盖磁盘故障。

可用环境变量：

| 变量 | 默认值 | 用途 |
|---|---|---|
| `TIME_ZONE` | `Asia/Shanghai` | 任务日期、周界线及连续打卡使用的家庭时区 |
| `DEFAULT_PARENT_PIN` | `1234` | 全新安装时的初始家长 PIN，首次登录后必须修改 |
| `DEVICE_AUTH` | 开启 | 设备授权门禁；设为 `off` 关闭（仅建议本地开发使用） |
| `AUTHORIZED_TOKENS_FILE` | 数据库所在目录下的 `authorized_tokens` | 已授权设备列表文件 |
| `BACKUP_INTERVAL_HOURS` | `24` | 自动备份间隔；设为 `0` 关闭 |
| `BACKUP_RETENTION` | `7` | 保留的备份份数 |
| `BACKUP_DIR` | 数据库所在目录下的 `backups` | 备份存储目录 |
| `JWT_SECRET` | 自动生成并保存到数据库 | 可选的自定义签名密钥；勿使用示例中的固定密钥 |
| `PUID` / `PGID` | `1000` / `1000` | Docker 中运行程序的用户与用户组，启动时自动接管数据目录；如需修改，请使用专用普通账户，不要使用管理员账户 |

升级会自动迁移旧数据库并保留账号、任务与历史记录。旧版只保存在前端演示库中的周频次设置无法从服务器恢复，需要在升级后重新设置。

### 设备授权与公网访问

所有页面、接口和错题照片都要求设备先获得授权，局域网访问也不例外，便于通过 frp 等方式在外使用：

- **配对**：未授权的浏览器只能看到一个配对页面，显示 6 位配对码（10 分钟内有效，过期可刷新）。家长在已授权设备的「备份与设置 → 设备授权」中输入配对码并填写设备名称，新设备会自动进入应用，之后长期有效。后台不会列出待批准的请求，只有知道新设备屏幕上配对码的人才能授权它。
- **第一台设备**：在服务器上运行 `docker exec taskie-app node src/cli.js approve-device <配对码> [设备名称]`；`list-devices` 列出已授权设备，`revoke-device <设备编号>` 撤销。
- **授权文件**：已授权设备保存在数据目录的 `authorized_tokens` 文件中，每行为“令牌 SHA-256、授权时间、设备名称”，只保存哈希、不保存令牌本身；可手动编辑，删除某一行即撤销该设备，无需重启。该文件不在应用备份中，迁移到新服务器后需要重新配对或一并复制。
- **授权记录**：新设备请求配对（配对码、来源 IP、浏览器）、授权、配对码输错、错误过多被暂停、撤销，以及通过服务器命令或手动编辑授权文件做的改动，都会记在「设备授权 → 最近的授权记录」里，并以 `设备授权：…` 开头写入容器日志（可在 Container Manager 的日志中查看），例如：`设备授权：授权了设备「妈妈的 iPhone」（在「客厅 iPad」上操作）`。来源 IP 依次显示 `X-Forwarded-For` 和直接连接的地址，可能被伪造，仅供参考；令牌不会出现在记录和日志中。服务器命令的操作会在服务端下一次收到请求时写入容器日志。记录保留最近 500 条，配对请求另外保留最近 300 条。
- **设备令牌**：保存在 `HttpOnly`、`SameSite=Lax` 的 Cookie 中，网页脚本无法读取；应用不允许跨域访问，其他网站无法借用已授权设备读取数据。在 iPhone 上，“添加到主屏幕”的应用与 Safari 存储相互独立，需要分别配对一次。
- **公网访问必须使用 HTTPS**：frp 默认转发明文 HTTP，令牌、PIN 和登录会话都会以明文在公网传输。请在 frps 的 HTTPS vhost 配置证书，或在公网服务器上用 Caddy/Nginx 终止 TLS，并转发 `X-Forwarded-Proto: https` 请求头，这样设备 Cookie 会带上 `Secure`。
- **不要按来源 IP 放行**：经过 frp 后所有请求都来自 frpc 所在主机，无法区分局域网与公网，因此本应用不做任何基于 IP 的免授权。

### 登录与网络行为

API 需要有效会话：家长管理账号、模板和备份，孩子仅可访问自己的记录与照片。会话有效期为 12 小时，PIN 登录连续失败 10 次后限制 15 分钟。首次使用默认家长 PIN（`1234`，或 `DEFAULT_PARENT_PIN` 设置的值）登录后，必须先设置新 PIN 才能使用家长后台；新 PIN 不能与默认 PIN 相同。修改家长 PIN 会让已有会话失效。

断网时操作会提示失败，不会切换到本地数据。浏览器已有的旧版登录状态需要重新登录。

### 原生运行时手动备份

以下命令用于原生 Node 部署，请先停止服务；运行中优先使用家长端快照备份。

- **数据库**：所有账号、任务、积分与生字生词均存储在单一文件 `backend/data.sqlite` 中；
- **图片**：所有错题照片均保存在 `backend/uploads/` 目录中；
- **一键全量备份**：
  ```bash
  tar -czvf taskie_backup_$(date +%Y%m%d).tar.gz backend/data.sqlite backend/uploads/
  ```
