# 🎒 小学生日常作业任务管理系统 (全栈版)

本项目是专为家庭场景（多孩子使用）定制的小学生日常作业与任务管理系统。前后端分离架构，专为 **iPad Air 5 横屏视口 (1180 × 820 px)** 进行深度视觉与触控优化定制。

---

## 🌟 系统核心特性

1. **多孩子账号体系**：
   - 首页可爱 Emoji 头像列表，支持多孩子独立选择进入；
   - 孩子可选设置个人数字 PIN 码保护，不同孩子任务数据、积分与徽章严格物理隔离；
   - 独立家长管理入口（默认 PIN: `1234`，支持自定义修改）。

2. **每日作业与任务看板（iPad Air 5 横屏深度优化）**：
   - 针对 **1180 × 820 px** 视口定制双栏大卡片布局，8项以内任务一屏全览无需滚动；
   - 触控目标 ≥ 48×48px，大尺寸圆角交互；
   - **中文字体甄选**：引入适宜小学语文与阅读的 **霞鹜文楷 (LXGW WenKai)** + 规范清晰的 **思源黑体 (Noto Sans SC)**，并搭配 **站酷快乐体** 艺术标题与圆润英文字体 **Nunito**；
   - **双模式任务配置**：支持“按固定星期重复”（如周一至周五每日生成）与“每周完成特定次数”（如每周完成3次阅读，实时跟踪周累计进度）。

3. **趣味激励系统与交互音效**：
   - **Web Audio 原生合成音效**（0 外部音频文件依赖，离线完美可用）：打卡完成金币音 (Coin)、全天完成胜利号角 (Fanfare)、勋章解锁叮当声 (Chime)、水滴轻触气泡音；
   - **声音控制**：顶部常驻大触控声音开关（🔊 / 🔇），支持状态持久化存储；
   - **连续打卡 (Streak)**：连续每日完成作业累计天数，火焰动效实时激励；
   - **成就徽章墙**：内置 8 款里程碑勋章，条件达成自动点亮并伴随庆祝音效。

4. **拍照错题本（触控裁剪 + 自动锐化压缩）**：
   - 调用 iPad 后置相机拍照或相册选图；
   - 支持多点触控与四角拖拽自由框选题目区域、90° 旋转校正；
   - Canvas 实时滤镜增强：原图 / 试卷清晰增强（拉普拉斯锐化矩阵提亮纸张底色）/ 黑白打印模式；
   - 服务端 **Sharp** 自动纠正 EXIF 拍摄方向并压缩保存为轻量 **WebP** 格式（150KB~250KB）。

5. **📖 生字本与 🔍 查笔画系统（全新上线）**：
   - **「🔍 查笔画」**：
     - 输入任意汉字，基于 **`hanzi-writer`** 在大尺寸米字格中**逐笔动态演示笔顺书写动画**（支持步进播放、暂停、重新书写）；
     - 显示部首、总笔画、带声调拼音并支持点击「🔊 朗读读音」标准普通话发音；
     - 提供大按钮「⭐ 加入生字本」，一键秒存至孩子专属生字库。
   - **「📖 生字本」**：
     - 田字格生字卡片流（霞鹜文楷优质书法字体展示）；
     - **拼音默认遮罩隐藏**（显示为问号），点击卡片「👁️ 拼音」按钮翻牌展开，契合小学生自主拼读背诵；
     - 点开卡片进入详情弹窗，支持手指在 iPad 屏幕上进行**笔顺描红临摹**练习；
     - 支持“已掌握” / “学习中”分类过滤。

6. **PWA 独立全屏运行模式**：
   - 已内置 Apple Web App 独立全屏标签与 Web Manifest；
   - 在 iPad Safari 中点击 **分享 ➡️ 添加到主屏幕**，即可生成独立全屏 App，去除顶底浏览器工具栏。

## 🛠️ 技术架构

- **前端 (`/frontend`)**：
  - **框架**：Vue 3 + Vite 5 + Pinia + Vue Router 4
  - **组件与视觉**：Tailwind CSS 3.x（原生定制组件）
  - **汉字与拼音**：`hanzi-writer` + `pinyin-pro` + `cnchar`
  - **图表**：Chart.js + vue-chartjs
  - **音效**：Web Audio API 自研波形合成引擎
- **后端 (`/backend`)**：
  - **运行时**：Node.js 20 LTS
  - **Web 框架**：Fastify 4.x
  - **数据库**：SQLite（`better-sqlite3` 单文件 `backend/data.sqlite`）
  - **图像流水线**：`sharp` (libvips 绑定)
  - **测试套件**：Node.js 原生 Test Runner（全量 29 项后端测试 + 27 项前端测试全部通过）
